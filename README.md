## 🌟 About The Repository

Welcome to my **Java Journey**! This repository is a complete, organized record of my Java learning path. Yahan aapko basics se lekar advanced projects tak sab kuch milega.

*   📝 **Daily Practice Code** — Regular practice code for every concept.
*   📘 **Important Notes** — Concise and easy-to-understand notes.
*   🛠️ **Mini & Major Projects** — Real-world projects applying concepts.
*   🧩 **DSA Practice** — Regular Data Structures and Algorithms practice.

## 📂 How to Use This Repository

1. **Clone the repository:**
   
       git clone https://github.com/khushiahirwar12/java-journey
   
2. **Navigate** to any topic folder.
3. **Open** the `.java` files in your preferred IDE.
4. **Compile and run:**
   
       javac FileName.java
       java FileName
